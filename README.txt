Awaz Ustad - offline version
1. Copy your Pashto and Hindko clips into the "audio" folder (cat_ps.mp3, cat_hk.mp3 ...).
2. Double-click START-Windows.bat (needs Python installed). The app opens at http://localhost:8000
   Or in a terminal inside this folder: python -m http.server 8000  then open http://localhost:8000
3. Press Start and allow the microphone. No internet needed.
Do not open index.html by double-clicking: the browser blocks the model and microphone that way.
